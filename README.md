# BloxFront

A Roblox territory-conquest game. BloxFront is a modified version of
[RoWorld](https://github.com/lukechatton/roworld) by Snick Co., which is itself a modified version of
[OpenFront](https://github.com/openfrontio/OpenFrontIO).
